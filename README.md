# PhotoTidy · Android

类 **Slidebox** 的照片整理器：**一张照片，四个方向，滑完就走。**
在你点确认之前，照片库不会有任何变化——整理全程只在内存里排队，提交时才整批落盘、只需一次系统授权。

**隐私优先**：仅通过 `MediaStore` 读写本地照片，无任何联网权限，照片物理上无法离开设备。

## 简介

PhotoTidy 是一款本地优先的 Android 照片整理工具，帮你用最快的手势把相册里堆积的照片快速分类、清理，全程不需要联网，也不依赖任何云服务。

**整理（核心）**

进入整理页后，照片以卡片形式一张张呈现，四个方向的手势覆盖大部分整理动作：

- **左滑**：保留，下一张
- **上滑**：放入系统回收站（30 天内可还原，之后由系统自动清空）
- **下滑**：撤销刚才的操作（拇指区内的「后悔药」）
- **底部相册栏**：横滑选择相册，一键把当前照片移到指定相册

所有滑动都只是「先排队」——照片库在提交前不会有任何变化。直到你点「提交」，才会整批一次性写入，并且只需一次系统授权（无论整理了多少张）。中途退出也不会丢：未提交的改动会落盘保存，下次打开接着整理。

**浏览与管理**

- **主页 / 相册页**：按月份、相册浏览照片，相册以自适应网格展示；顶部下拉可切换「最近 / 全部相册 / 全部月份」。
- **回收站页**：查看系统回收站中的照片，支持勾选、还原或彻底删除。
- **设置页**：调整动态取色（Material You）、纯黑模式、手势灵敏度等，并带有未处理数量的回收站入口。

**隐私与安全**

- 仅通过系统 `MediaStore` 读写本地照片，无任何联网权限，照片物理上无法离开设备。
- 不可逆操作（如彻底删除）一律走系统确认对话框，多一次系统级确认。
- 首次进入会自动弹出「怎么用」引导，五条手势说明一目了然。

## 特色

- **整理零打扰**：所有滑动只改内存，提交时才整批落盘，并且一次系统授权覆盖全部照片——滑几百张不会弹一次系统框，也不会因某张写失败卡住节奏。
- **撤销无负担**：改动在落盘前都还在内存里，撤销就是一次回滚，不存在「已写入需要反向补偿」的麻烦。
- **本地优先、绝不联网**：不申请「所有文件访问权限」，只声明图片读取权限，靠会话级提交解决授权粒度问题，而非交出全盘读写。
- **自适应布局**：手机用底部导航，平板（≥600dp）自动切侧边导航栏，相册网格随宽度自适应。
- **个性化外观**：支持 Material You 动态取色、纯黑模式与手势灵敏度调节，全部实时生效。
- **轻量可靠**：仅依赖 `MediaStore`，无第三方数据库与自建存储；超大照片库也只累积相册/月份计数，内存占用恒定，未提交的改动还会落盘，意外退出不丢进度。

## 技术栈

- Jetpack Compose + Material 3
- Kotlin
- `compileSdk 36` / `targetSdk 36` / `minSdk 31`
- 数据访问：`MediaStore`（无第三方数据库、无自建存储）

## 构建运行

需要 JDK 17+、Android SDK Platform 36、Build Tools 36.x、Gradle 8.13+（wrapper 已锁定）。

```bash
./gradlew :app:assembleDebug      # 调试包
./gradlew :app:assembleRelease    # 发布包（R8 混淆 + 资源收缩）
./gradlew :app:lintDebug          # 静态检查
```

也可以直接用 Android Studio 打开项目根目录 Run。
